# Simple To-Do List Application

A lightweight, client-side to-do list application built with vanilla HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as complete/incomplete
- Delete tasks
- Persistent storage using localStorage
- Responsive design
- Task counter showing completion progress

## Usage

1. Open `index.html` in any modern web browser
2. Type a task in the input field
3. Click "Add" or press Enter to add the task
4. Click the checkbox to mark a task as complete
5. Click "Delete" to remove a task

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and layout
- `app.js` - Application logic and functionality

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge).
